# Water drain Tools

## Info

This Is Full SRC Of Kingslet's Water Drain Video Made By Kingslet Gaming. Minecraft 1.21.11 fabric

Youtube: https://www.youtube.com/@Kingslet_Gaming
Insta: https://www.instagram.com/kingslet_yt
## Setup
To Download this mod go to build/lib/ and download water-drain-tools-1.0.0.jar

Mod requires Fabric API

After apply the mod need to set the place where water spawn during event using /waterevent set pos1 / pos2 (have to set pos1 and pos2)
to add shopkeeper just use /shopkeeper create
to start event use /waterevent start lvl1,lvl2,lvl3
to start event directly without wait 10min just use /waterevent start dirlvl1, dirlvl2, dirlvl3
